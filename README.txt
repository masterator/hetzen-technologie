HOW TO USE
1. Keep all files in the same folder structure.
2. Open index.html in a browser to preview.
3. Upload the entire folder to your web host.
4. In script.js, add your WhatsApp number as digits only if you want to connect WhatsApp buttons later.
5. Replace hello@hetzentechnologies.co.za with the final business email once the domain/email is set up.
